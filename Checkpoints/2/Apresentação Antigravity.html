Arquitetura Experimental em 2 Etapas

Isolamento rigoroso entre raciocínio profundo e formatação estruturada de matrizes

  • Dataset Base: 400 tasks de treino originais do ARC-AGI avaliadas com Gemma 31B (76.00% acurácia base - 304 acertos).
  • Isolamento de Amostras para Teste: Apenas os 304 problemas acertados foram submetidos às perturbações para testar a perda real de generalização.
  • Pool Paralelo Multi-Chaves com Circuit Breaker: 4 chaves de API isoladas executando requisições com controle de cotas (16K TPM).

    • 🔬 Pipeline de Execução (solver.py)

    Etapa 1: High Thinking CoT (Temperatura T = 0.6, 16k tokens)

    Exploração de hipóteses, deduções de simetria e raciocínio espacial profundo (~200s - 800s).

    Etapa 2: Extração Numérica (Thinking: MINIMAL, Temperatura T = 0.0)

    Formatação pura e determinística (greedy) da predição final em bloco numérico <prediction> sem nova carga de raciocínio (~4s).

    Geração das Novas Tasks

    Mecanismo das Transformações 2D (task_generator.py)

    Como as matrizes originais foram manipuladas para criar novos desafios com invariância e perturbação

    🔄 1. Rotação Espacial

    Gira as matrizes em 90° CW, 180° ou 270° (90° CCW) mantendo a conectividade relativa.

    Original → 90° Horário
    1 2 0  →  0 4 1
    4 5 0  →  0 5 2
    0 0 0  →  0 0 0

    🪞 2. Reflexão / Espelho

    Espelhamento Horizontal (inverte colunas) ou Vertical (inverte linhas).

    Original → Espelho Horiz.
    1 2 0  →  0 2 1
    4 0 0  →  0 0 4
    3 3 0  →  0 3 3

    🎨 3. Permutação de Cores

    Mapeamento bijetivo que permuta a paleta (ex: 2→4, 3→8), preservando o fundo 0.

    Paleta [1→7, 2→3]
    1 1 2  →  7 7 3
    0 2 0  →  0 3 0
    2 0 1  →  3 0 7

    🧬 4. Merged (Compostas)

    Composição combinando 2 famílias (ex: Giro 90° CW + Cores [1→7, 2→4, 3→8]).

    Original → Giro 90° + Cor
    1 2 0  →  0 0 7
    0 3 0  →  0 8 4
    0 0 0  →  0 0 0
    ⚙️ Consistência nos Exemplos: Ao transformar uma task, a mesma regra é aplicada deterministicamente em todos os pares de demonstração (train) e no input/output de teste (test), garantindo que a task continue logicamente solucionável.

    Análise Teórica & Hipóteses

    Hipótese 1: Memorização Prévia vs. Demonstrações

    O fenômeno do Prior Memorization Override (Contaminação de Treinamento)

    🧠 O que a Teoria prevê?

    Grandes Modelos de Linguagem são expostos a repositórios do ARC-AGI durante o pré-treinamento. Quando a task original é apresentada, o modelo muitas vezes não "induz a regra do zero", mas recupera um padrão pré-indexado de sua memória associativa.

    Efeito Perturbação: Ao modificarmos as cores ou a orientação dos grids, quebramos a correspondência canônica. O modelo sofre uma colisão cognitiva entre o que ele memorizou e o que as novas demonstrações mostram.

    🔍 O que os Dados revelaram?

    • Em tasks compostas (Merged), o modelo frequentemente reconhece a "família" da task, mas reproduz no raciocínio a regra de cores da task original em vez da nova regra demonstrada no JSON.
    • Isso explica a queda dramática de 76.0% para 44.5% em Merged, acompanhada pelo maior gasto de tokens (16.222), pois o modelo entra em conflito e tenta reconciliar premissas incompatíveis.
    Estudo de Caso Real

    Caso Real 1: Merged Task d965528e.json

    Evidência explícita de memorização da regra da task original (f1cefba8.json)

    📄 O Raciocínio gerado pelo Modelo (LLM Reasoning)

    "Transpose the grid. The inner rectangle of the output 
takes the color of the input's outer rectangle (A). 
The outer rectangle of the output takes a transformed 
color of the input's inner rectangle (B), 
following the cycle 2 -> 3 -> 8 -> 2 (and 4 -> 4)."
    🚨 O Erro Fatal: O ciclo 2 -> 3 -> 8 -> 2 pertencia à task original! No novo JSON gerado, esse ciclo foi alterado pela permutação de cores. O modelo ignorou os exemplos de treino e aplicou a memória pré-treinada cegamente.

    🎯 Diagnóstico da Falha

    • Acerto Espacial: O modelo acertou a transposição geométrica (input 18x19 virou output 19x18).
    • Falha Semântica: A ancoragem de cores foi contaminada pela memória da base do ARC.
    • Typos Visuais: O modelo "comeu" pixels nas bordas (imprimiu 0 0 0 2 1 1... em vez de 0 0 0 2 2 1...), rompendo a continuidade geométrica.
    Análise Teórica & Hipóteses

    Hipótese 2: Viés de Fechamento Geométrico

    Alucinação por "Overfitting Topológico" em Formas Abertas

    📐 A Indução por Conectividade

    Modelos de linguagem treinados em dados 2D sofrem de um forte viés de preenchimento ("Gestalt Prior"): a tendência de assumir que grupos de pixels pertencem a contornos fechados (caixas, retângulos, polígonos completos).

    Quando a regra lógica estrita exige apenas conectar pontos colineares (formando uma linha ou um "L"), o modelo muitas vezes alucina conexões extras para "fechar o retângulo".

    🔍 O Caso da Task Rotacionada

    • Regra Real: "Se dois pontos da mesma cor compartilham linha ou coluna, conecte-os".
    • Pontos do Input: Três pontos em (3,6), (15,6) e (15,21). A união lógica forma estritamente um "L".
    • O que o Modelo fez: Inventou uma barra horizontal na linha 3 e uma vertical na coluna 21, desenhando uma caixa retangular fechada.

    Hipótese 3: Discretização e Erros de Off-By-One

    Estudo de Caso na Task Refletida 0ac8ac11.json

    📝 Regra Perfeita vs. Execução Falha

    Na task 0ac8ac11.json, o modelo deduziu a regra com perfeição em linguagem natural: 

    "Identify columns containing color 5, rank them 
by height in descending order, and replace color 5 
with colors 1, 2, 3, and 4 respectively based on that rank."

    No entanto, o grid gerado foi classificado como INCORRECT por severos erros de indexação espacial.

    ❌ Erros Concretos da Matriz Gerada

    • Alucinação de Posições: Criou colunas nas posições 0, 2, 4 e 7, enquanto as posições reais refletidas eram 1, 3, 5 e 7.
    • Erro de Altura (+1 pixel): As alturas reais eram 8, 7, 5 e 3. A IA gerou alturas 9, 8, 6 e 4.
    • Inversão de Ranking: Atribuiu a cor 1 à 3ª maior coluna devido à confusão com a inversão horizontal de coordenadas.

    Conclusões e Próximos Passos

    O que os experimentos revelam sobre a verdadeira inteligência de LLMs no ARC-AGI?

    🚩 Principais Descobertas

    • Falsa Invariância Espacial: LLMs com CoT não possuem representação espacial contínua; perturbações 2D simples degradam o acerto em até 31,5 pontos percentuais (de 76,0% para 44,5%).
    • Contaminação de Treino como Muleta: A acurácia original de 76% é inflada pela memorização prévia dos benchmarks.
    • Raciocínio Linguístico ≠ Execução Matricial: O modelo frequentemente acerta a descrição textual da regra, mas erra a transposição para matrizes numéricas.
